# ozee — Portfolio

Personal site of **ozee**, a backend-first product engineer for business systems: HR & payroll, import compliance, ERP reporting, logistics, payments and other regulated integrations.

**Live:** https://mfrlab.github.io

## What's on the page

- **Interactive rule engine demo.** Four import documents get cross-checked against each other in the browser. Try "Spot the typos" and see if you find both mistakes before the engine does.
- **Selected work.** Production systems across six business domains, plus integrations with banks, payment gateways, tax invoicing, e-signature and identity verification.
- **Experience.** From an early-stage startup through scaling, due diligence and acquisition, to corporate.
- **How I work.** Shipping fast with AI-assisted development, kept safe by design docs, reviewed diffs and tests.

## Tech

One `index.html` file with no framework, no build step and no dependencies apart from Google Fonts.

- Plain HTML, CSS and vanilla JavaScript
- Light and dark theme, which follows the system setting and can be toggled
- Scroll-triggered animations that respect `prefers-reduced-motion`
- Responsive down to small phone screens

## Run locally

```bash
git clone https://github.com/mfrlab/mfrlab.github.io.git
cd mfrlab.github.io
open index.html        # or: python3 -m http.server 8000
```

## Note

All data in the demo (company names, document numbers, quantities) is fictional. Project descriptions are written at the domain level and contain no client or employer data.
